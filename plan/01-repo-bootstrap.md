### Task 2: 将已有 photocraft 目录转为钉死的 submodule

**Files:**
- Create: `.gitmodules`
- Modify: gitlink at `thirdparty/photocraft`

**Interfaces:**
- Consumes: 已存在的 `thirdparty/photocraft` 嵌套仓库 @ `287352bf92d56817db9a510e506551f394a68ea4`
- Produces: `.gitmodules` + 根仓库记录的 gitlink

- [ ] **Step 1: 验证嵌套仓库 SHA 与干净状态**

```bash
cd /Volumes/my/github/SimplePhoto/thirdparty/photocraft
git rev-parse HEAD
git remote -v
git status -sb
```

Expected:
- HEAD = `287352bf92d56817db9a510e506551f394a68ea4`
- origin = `git@github.com:storytold/photocraft`
- 工作区干净（无未提交改动）。若有本地改动，先 stash/丢弃或做成 patch（见 `patches.md`），再继续。

- [ ] **Step 2: 用 submodule absorb 或等价流程登记（保留现有文件）**

若 git 版本支持（Git 2.12+），在根仓库执行：

```bash
cd /Volumes/my/github/SimplePhoto
# 若 thirdparty/photocraft 还不是 submodule：
git submodule add --force git@github.com:storytold/photocraft thirdparty/photocraft
cd thirdparty/photocraft
git checkout 287352bf92d56817db9a510e506551f394a68ea4
cd ../..
git add .gitmodules thirdparty/photocraft
git status
```

若 `git submodule add` 因目录已存在失败，改用：

```bash
cd /Volumes/my/github/SimplePhoto
# 1) 备份嵌套 .git 路径信息
test -d thirdparty/photocraft/.git -o -f thirdparty/photocraft/.git

# 2) 手写 .gitmodules
cat > .gitmodules <<'EOF'
[submodule "thirdparty/photocraft"]
	path = thirdparty/photocraft
	url = git@github.com:storytold/photocraft
EOF

# 3) 确保子仓库在钉死 commit
git -C thirdparty/photocraft fetch origin
git -C thirdparty/photocraft checkout 287352bf92d56817db9a510e506551f394a68ea4

# 4) 将 gitlink 加入索引（注意：add 的是 submodule，不是其内部文件）
git add .gitmodules
git submodule absorbgitdirs thirdparty/photocraft 2>/dev/null || true
git add thirdparty/photocraft
git submodule status
```

Expected: `git submodule status` 显示以空格或 `+`/`-` 前缀的 `287352b… thirdparty/photocraft`；根 `git ls-files -s thirdparty/photocraft` 模式为 `160000`。

- [ ] **Step 4: 写复现说明到 `scripts/bootstrap-submodule.sh`（可执行文档）**

**Files:** Create: `scripts/bootstrap-submodule.sh`

```bash
#!/usr/bin/env bash
set -euo pipefail
ROOT="$(cd "$(dirname "$0")/.." && pwd)"
PIN="287352bf92d56817db9a510e506551f394a68ea4"
cd "$ROOT"
git submodule update --init --recursive
git -C thirdparty/photocraft fetch origin
git -C thirdparty/photocraft checkout "$PIN"
echo "photocraft HEAD=$(git -C thirdparty/photocraft rev-parse HEAD)"
test "$(git -C thirdparty/photocraft rev-parse HEAD)" = "$PIN"
```

```bash
chmod +x scripts/bootstrap-submodule.sh
./scripts/bootstrap-submodule.sh
git add scripts/bootstrap-submodule.sh
git commit -m "chore: add submodule bootstrap script pinned to photocraft SHA"
```

Expected: 脚本打印的 HEAD 等于 `287352bf92d56817db9a510e506551f394a68ea4`。
