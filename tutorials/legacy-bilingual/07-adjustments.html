色调与颜色调整

Tone and color adjustments

大多数照片先要处理「亮暗是否合理、颜色是否可信」，再谈风格。常用入口在 图像 → 调整：它们直接改当前图层的像素。若希望以后还能改参数，应改用调整图层（见第 14 章）。

Most photos need believable lightness and color before they need a “look.” The usual entry point is Image → Adjustments, which writes into the current layer’s pixels. If you want to revisit the settings later, use an adjustment layer instead (chapter 14).

先掌握这几个

Start with these

  • 色阶（Levels，⌘L / Ctrl+L）：用黑、灰、白三个滑块设定暗部、中间调和亮部。适合把发灰的照片重新拉开反差。
  • 曲线（Curves，⌘M / Ctrl+M）：在坐标系里推点，可做更细的对比度和分区校正。S 形曲线会增加反差。
  • 色相 / 饱和度（Hue/Saturation）：改整体或某个颜色范围的色相、饱和度与明度。适合让过饱和的衣服收敛，或微调偏色。
  • 亮度 / 对比度：更直观，但不如色阶和曲线精细，适合轻微调整。
  • Levels (⌘L / Ctrl+L): black, gray, and white sliders set shadows, midtones, and highlights. Useful when a photo looks washed out.
  • Curves (⌘M / Ctrl+M): push points on a graph for finer contrast and regional correction. An S-curve increases contrast.
  • Hue/Saturation changes hue, saturation, and lightness globally or in a color range — useful for calming a loud garment or easing a color cast.
  • Brightness/Contrast is more literal but less precise than Levels or Curves; keep it for small moves.

在 SimplePhoto 中

In SimplePhoto

上述命令都在 图像 → 调整。对话框通常带预览，确认后写入历史记录，可用还原或历史面板撤回。你也可以用 图层 → 新建调整图层 创建色相/饱和度、曲线等调整图层，把效果与像素分开。属性面板里仍可继续修改这些调整图层。

These commands live under Image → Adjustments. Dialogs typically preview first; confirming writes a History step you can undo. You can also choose Layer → New Adjustment Layer for Hue/Saturation, Curves, and similar, so the effect stays separate from the pixels. The Properties panel continues to edit those adjustment layers.

建议顺序：先修正曝光和黑白场（色阶或曲线），再处理白平衡或色偏，最后才加风格化的颜色。每次只做一个明确的目标，避免同时拖十个滑块却说不清为什么。

A reliable order: fix exposure and the black/white points first (Levels or Curves), then a color cast, and only then a stylized grade. Change one clear thing at a time instead of moving ten sliders you cannot explain.

仅 Photoshop 的概念

Photoshop-only notes

Adobe Camera Raw 滤镜的云端配置文件、神经滤镜上色、以及生成式「重新着色」不属于 SimplePhoto 的保证功能。若菜单里没有某一项，就把它当作 Photoshop 专有，改用本编辑器已有的调整或相机原始数据相关工具（若该文件类型可用）。

Cloud Camera Raw profiles, Neural Filter colorize, and generative recolor are not guaranteed SimplePhoto features. If a command is missing from the menu, treat it as Photoshop-specific and use the adjustments or camera-raw tools that are actually present for that file type.
