キーボードショートカット

ショートカットはポインタの移動を減らしますが、一度に全部覚える必要はありません。ツールキーと、毎日使うファイル／補正コマンドから学びます。表は SimplePhoto（PhotoCraft）の初期設定で、Photoshop に近いです。macOS では ⌘、Windows / ChromeOS では Ctrl、⌥ は Alt、⇧ は Shift です。環境設定でショートカットを割り当て直した場合は、アプリの現在の割り当てが優先されます。

SimplePhoto では

設定 / 環境設定のキーボード欄（Photoshop のキーボードショートカットダイアログに近い）で、割り当てを確認・変更できます。複数のツールが同じキーを共有するときは、もう一度押すとグループを巡回します。スペースは一時的に手のひらツールへ切り替わるので、描画中にパンできます。

ツール

  • V — 移動
  • M — 選択ツール
  • L — なげなわ
  • W — 自動選択 / クイック選択 / オブジェクト選択
  • C — 切り抜き
  • B — ブラシ
  • E — 消しゴム
  • T — 文字
  • J — 修復グループ
  • S — コピースタンプ
  • G — グラデーション / ペイントバケツ
  • I — スポイト
  • P — ペン
  • U — シェイプ
  • O — 覆い焼き / 焼き込み / スポンジ
  • H — 手のひら
  • Z — ズーム
  • R — 回転ビュー

ファイル、編集、補正

  • ⌘O / Ctrl+O — 開く
  • ⌘S / Ctrl+S — 保存
  • ⇧⌘S / Ctrl+Shift+S — 名前を付けて保存
  • ⌘⌥⇧W / Ctrl+Alt+Shift+W — 書き出し形式を指定
  • ⌘T / Ctrl+T — 自由変形
  • ⌘⌥I / Ctrl+Alt+I — 画像サイズ
  • ⌘⌥C / Ctrl+Alt+C — カンバスサイズ
  • ⌘L / Ctrl+L — レベル補正
  • ⌘M / Ctrl+M — トーンカーブ
  • ⇧⌘N / Ctrl+Shift+N — 新規レイヤー（ダイアログ）
  • F7 — レイヤーパネル
  • F5 — ブラシ設定

これらが体に入ると、あまり使わないコマンドも足しやすくなります。次の画像では、ツールバーを見る回数を減らしてみてください。
