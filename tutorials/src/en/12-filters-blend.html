Chapter 12 · Effects

Filters and blend modes

A filter changes how a layer or selection looks: blur, sharpen, noise, distort, and so on. A blend mode decides how that layer combines with what is under it — lighten, darken, add contrast, or keep texture only. Both are easy to overdo, so compare before and after often.

In SimplePhoto

The Filter menu is grouped by category, for example Gaussian Blur under Blur. Many filters open a preview dialog and write a History step. Smart Objects can hold Smart Filters so you can edit or toggle them later (chapter 14). Blend modes live in the Layers panel dropdown (keyboard or wheel may be available, depending on the control). Useful starting points: Multiply to darken, Screen to lighten, Overlay / Soft Light for contrast, and Luminosity to borrow lightness without taking as much color.

Useful combinations

  • Duplicate a layer, apply Gaussian Blur, set the copy to Soft Light, and mask the effect for a gentle glow.
  • Set a texture layer to Overlay or Soft Light and lower opacity to add grain to a flat color.
  • Sharpen (for example Unsharp Mask) near the end, and judge it at 100% zoom so you do not create halos that only show up later.

Photoshop-only notes

Neural Filters, some cloud stylization filters, and Firefly effects are Photoshop product features. If the same name is absent from SimplePhoto’s Filter menu, do not hunt for it from a Photoshop screenshot.
