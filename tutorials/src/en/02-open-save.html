Open, save, and export

Before you edit, decide how a file comes in and what it should become. Saving usually keeps an editable structure (layers in a PSD, for example). Exporting makes a finished file for the web, print, or someone else (JPEG, PNG, WebP, and similar).

Open and New

  • File → Open (⌘O / Ctrl+O) picks an existing image on disk.
  • File → New starts a blank canvas with a width, height, and background.
  • The Home screen offers the same Open and New actions.

In SimplePhoto

As a Chrome extension, Open uses the browser file picker. Editing stays on your machine; SimplePhoto does not upload your photo to a SimplePhoto server. File → Save (⌘S / Ctrl+S) and Save As (add Shift) write an editable file. File → Export → Export As (⌘⌥⇧W / Ctrl+Alt+Shift+W) opens options for format and size; Quick Export as PNG is handy for a transparent bitmap right away. In the browser, save/export usually appears as a download.

Choosing a format

  • PSD or another layered format: prefer this while you still need layers, masks, and type.
  • PNG: transparency, or less willingness to use lossy compression.
  • JPEG: compact photos for sharing; lossy, and no transparency.
  • WebP and others: pick them in Export As for a target, and check the preview before you settle on quality.

Photoshop-only notes

Cloud documents, Lightroom sync, Creative Cloud version history, and “save to Adobe cloud” are not part of SimplePhoto. This extension also does not request a downloads permission, so you will not get desktop-style save-in-place over a chosen folder; the browser download flow is used instead.
