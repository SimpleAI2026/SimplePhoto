Layers

Layers behave like stacked sheets of film: the one above can hide the one below, yet you can move, hide, or fade it without destroying the pixels underneath. Serious editing almost always starts with “do not paint yourself into a single background layer.”

What the Layers panel is for

  • See the stack order and drag to rearrange.
  • Click the eye to show or hide a layer.
  • Change opacity and the blend mode (you will use this constantly later).
  • Group related layers so the list stays readable.

In SimplePhoto

Open Window → Layers (F7). Create a layer from the Layer menu or the panel button. ⇧⌘N / Ctrl+Shift+N opens the New Layer dialog; ⌥⇧⌘N / Ctrl+Alt+Shift+N creates one immediately. You can also duplicate, merge down, or flatten. Rasterize when you need type, shapes, or a Smart Object as ordinary pixels. Converting a layer to a Smart Object supports non-destructive transforms (see chapter 14).

Practical habits

Name layers so you can still read the stack next week. Keep skin work, sky work, and type on separate layers. If a pass goes wrong, hide that layer or delete it; the background remains. If the Background layer will not move, convert it to a normal layer first.

Photoshop-only notes

Video layers, some 3D layer types, and layers linked to Adobe Stock or cloud libraries are outside this extension’s scope. SimplePhoto’s layer model is aimed at still-image editing and compositing.
