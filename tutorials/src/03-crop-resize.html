裁剪、图像大小与画布大小

Crop, image size, and canvas size

这三项常常被混为一谈，但做的事情不同：裁剪丢掉框外的画面；图像大小改变像素数量（放大或缩小整张图）；画布大小改变工作区域，可以留出空白边，也可以裁掉边缘，但不重新采样主体内容的方式与「图像大小」不同。

These three are easy to confuse. Crop throws away pixels outside a frame. Image Size changes how many pixels the picture has (enlarging or shrinking the whole image). Canvas Size changes the working area — you can add empty margins or trim edges — without resampling the subject the way Image Size does.

在 SimplePhoto 中

In SimplePhoto

  • 工具栏 裁剪工具（C）：拖出裁剪框，确认后应用。同组还有透视裁剪，用于矫正有透视的边缘。
  • 图像 → 图像大小（⌘⌥I / Ctrl+Alt+I）：改宽高，注意是否勾选约束比例，以及重采样方式。
  • 图像 → 画布大小（⌘⌥C / Ctrl+Alt+C）：改画布尺寸和锚点（新空间加在哪一侧）。
  • The Crop Tool (C) draws a crop box; confirm to apply. The same group includes Perspective Crop for edges that recede in perspective.
  • Image → Image Size (⌘⌥I / Ctrl+Alt+I) changes width and height. Watch whether proportions are constrained, and which resampling method you chose.
  • Image → Canvas Size (⌘⌥C / Ctrl+Alt+C) changes the canvas and the anchor (which side new space is added on).

什么时候用哪一个

When to use which

  • 只要重新构图、去掉多余背景：用裁剪。
  • 要交一张「最长边 2000 像素」的图：用图像大小。
  • 要给海报加一圈白边，或把画布改成正方形而不拉伸照片：用画布大小，再视需要移动图层。
  • To reframe and drop extra background: crop.
  • To deliver an image whose long side is 2000 pixels: Image Size.
  • To add a white border, or to make a square canvas without stretching the photo: Canvas Size, then move the layer if needed.

把照片放大很多时，细节不会凭空变清晰，只是像素被估算出来。能拍得更大就不要过分上采样。缩小则通常更安全，但仍要看是否还有文字或细线需要保持清晰。

Enlarging a photo a long way does not invent real detail; new pixels are estimated. Prefer capturing more resolution over heavy upsampling. Shrinking is usually safer, but check type and thin lines.

仅 Photoshop 的概念

Photoshop-only notes

生成式扩展（Generative Expand）用 AI 凭空补出裁剪框外的内容，这是 Photoshop 的云端功能，SimplePhoto 没有对等按钮。需要补景时，请改用仿制、修补或自己导入另一张素材。

Generative Expand fills crop-frame padding with AI-generated content. That is a Photoshop cloud feature; SimplePhoto has no equivalent button. To extend a scene, clone, patch, or place another image yourself.
