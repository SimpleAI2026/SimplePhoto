열기, 저장, 내보내기

편집하기 전에 파일이 어떻게 들어오고, 무엇을 만들어야 하는지 정하세요. 저장은 보통 다시 편집할 수 있는 구조(예: PSD의 레이어)를 남깁니다. 내보내기는 웹, 인쇄, 다른 사람을 위한 완성 파일(JPEG, PNG, WebP 등)을 만듭니다.

열기와 새로 만들기

  • 파일 → 열기(⌘O / Ctrl+O)는 디스크의 기존 이미지를 고릅니다.
  • 파일 → 새로 만들기는 너비, 높이, 배경이 있는 빈 캔버스를 시작합니다.
  • 홈 화면에도 같은 열기와 새로 만들기 동작이 있습니다.

SimplePhoto에서

Chrome 확장 프로그램이므로 열기는 브라우저 파일 선택기를 사용합니다. 편집은 내 기기에서 이루어지며, SimplePhoto가 사진을 SimplePhoto 서버로 업로드하지 않습니다. 파일 → 저장(⌘S / Ctrl+S)와 다른 이름으로 저장(Shift를 추가)은 편집 가능한 파일을 씁니다. 파일 → 내보내기 → 다른 형식으로 내보내기(⌘⌥⇧W / Ctrl+Alt+Shift+W)는 형식과 크기 옵션을 열고, PNG로 빠르게 내보내기는 바로 투명 비트맵을 받을 때 유용합니다. 브라우저에서는 저장/내보내기가 보통 다운로드로 나타납니다.

형식 고르기

  • PSD 또는 다른 레이어 형식: 레이어, 마스크, 문자가 아직 필요하면 이쪽을 우선합니다.
  • PNG: 투명도가 필요하거나, 손실 압축을 피하고 싶을 때.
  • JPEG: 공유용으로 용량이 작은 사진. 손실 압축이며 투명도가 없습니다.
  • WebP 등: 다른 형식으로 내보내기에서 목적에 맞게 고르고, 품질을 정하기 전에 미리보기를 확인하세요.

Photoshop 전용 참고

클라우드 문서, Lightroom 동기화, Creative Cloud 버전 기록, “Adobe 클라우드에 저장”은 SimplePhoto에 없습니다. 이 확장 프로그램은 downloads 권한도 요청하지 않으므로, 선택한 폴더에 데스크톱처럼 제자리 저장되지 않고 브라우저 다운로드 흐름을 사용합니다.
