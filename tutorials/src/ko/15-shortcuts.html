키보드 단축키

단축키는 포인터 이동을 줄이지만, 한꺼번에 다 외울 필요는 없습니다. 도구 키와 매일 쓰는 파일·조정 명령부터 배우세요. 표는 SimplePhoto(PhotoCraft) 기본값이며 Photoshop에 가깝습니다. macOS에서는 ⌘, Windows / ChromeOS에서는 Ctrl, ⌥는 Alt, ⇧는 Shift입니다. 환경 설정에서 단축키를 다시 매겼다면 앱의 현재 할당이 우선합니다.

SimplePhoto에서

설정 / 환경 설정의 키보드 섹션(Photoshop의 키보드 단축키 대화 상자와 비슷)에서 할당을 검토하거나 바꿀 수 있습니다. 여러 도구가 키를 공유하면 다시 눌러 그룹을 순환합니다. Space는 일시적으로 손 도구로 바뀌어, 그리는 동안 화면을 이동할 수 있습니다.

도구

  • V — 이동
  • M — 선택 윤곽
  • L — 올가미
  • W — 자동 선택 / 빠른 선택 / 오브젝트 선택
  • C — 자르기
  • B — 브러시
  • E — 지우개
  • T — 문자
  • J — 복구 그룹
  • S — 복제 도장
  • G — 그라데이션 / 페인트 통
  • I — 스포이드
  • P — 펜
  • U — 도형
  • O — 닷지 / 번 / 스펀지
  • H — 손
  • Z — 확대/축소
  • R — 보기 회전

파일, 편집, 조정

  • ⌘O / Ctrl+O — 열기
  • ⌘S / Ctrl+S — 저장
  • ⇧⌘S / Ctrl+Shift+S — 다른 이름으로 저장
  • ⌘⌥⇧W / Ctrl+Alt+Shift+W — 다른 형식으로 내보내기
  • ⌘T / Ctrl+T — 자유 변형
  • ⌘⌥I / Ctrl+Alt+I — 이미지 크기
  • ⌘⌥C / Ctrl+Alt+C — 캔버스 크기
  • ⌘L / Ctrl+L — 레벨
  • ⌘M / Ctrl+M — 곡선
  • ⇧⌘N / Ctrl+Shift+N — 새 레이어(대화 상자)
  • F7 — 레이어 패널
  • F5 — 브러시 설정

이것들이 손 기억에 남으면, 덜 쓰는 명령도 더하기 쉽습니다. 다음 이미지에서는 도구 모음을 더 적게 들여다보세요.
