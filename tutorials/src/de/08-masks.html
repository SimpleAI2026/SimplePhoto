Kapitel 08 · Kern

Ebenenmasken

Eine Maske ist eine Graustufenkarte der Sichtbarkeit einer Ebene: Weiß zeigt, Schwarz verbirgt, Grau ist teilweise. Sie ist kein Radiergummi — die Pixel bleiben, Sie können verborgene Bereiche später zurückmalen. Das ist der Schritt von „ich kann retuschieren“ zu „ich kann es mir noch anders überlegen“.

In SimplePhoto

Fügen Sie eine Ebenenmaske über das Ebenenbedienfeld oder das Menü Ebene hinzu (alles einblenden, alles ausblenden oder anhand einer Auswahl ein-/ausblenden). Ist eine Auswahl aktiv, folgt die Maske ihr oft sofort. Malen Sie Schwarz oder Weiß auf der Maske; klicken Sie das Ebenenminiaturbild, um Pixel zu bearbeiten, und das Maskenminiaturbild für die Maske. Vektormasken stehen bereit, wenn Sie eine harte, pfadbasierte Kante wollen, die sich weiter ändern lässt.

Typische Anwendungen

  • Eine freigestellte Person auf einen neuen Hintergrund setzen und Haare auf der Maske verfeinern, statt Hintergrundpixel zu löschen.
  • Eine Einstellungsebene auf Himmel oder Haut begrenzen: eine Maske hinzufügen und Bereiche ausmalen, die sich nicht ändern sollen.
  • Auf der Maske einen Verlaufsübergang (unterschiedliche Belichtung oben und unten) bauen; das lässt sich leichter korrigieren, als die Pixel selbst zu bemalen.

Prüfen Sie eine Maske auf Lücken oder matschige Kanten. Sitzt etwas nicht, ändern Sie die Pinselhärte oder führen Sie Auswählen und maskieren erneut aus und geben eine neue Maske aus — das ganze Dokument müssen Sie nicht neu aufbauen.

Nur in Photoshop

Einige Cloud-Schaltflächen „Motiv auswählen und automatisch maskieren“ und Aufgabenmasken im Arbeitsbereich Generatives Füllen gehören zu Photoshops Produktfluss. SimplePhoto baut Masken mit lokalen Auswahlwerkzeugen und Auswählen und maskieren.
