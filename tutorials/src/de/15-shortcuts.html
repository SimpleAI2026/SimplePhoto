Kapitel 15 · Referenz

Tastaturkürzel

Tastenkürzel verringern Wege mit dem Zeiger, aber Sie müssen sie nicht alle auf einmal lernen. Lernen Sie die Werkzeugtasten und die Datei- oder Korrekturbefehle, die Sie täglich nutzen. Die Tabelle folgt den Vorgaben von SimplePhoto (PhotoCraft), die nahe an Photoshop liegen. Auf macOS gilt ⌘, unter Windows / ChromeOS Strg; ⌥ ist Alt, ⇧ ist Umschalt. Wenn Sie Kürzel in den Vorgaben umbelegt haben, gilt die aktuelle Zuordnung der App.

In SimplePhoto

Prüfen oder ändern Sie Bindungen im Tastaturabschnitt von Einstellungen / Vorgaben (ähnlich dem Dialog Tastaturbefehle in Photoshop). Teilen sich mehrere Werkzeuge eine Taste, drücken Sie sie erneut, um die Gruppe zu durchlaufen. Die Leertaste wechselt vorübergehend zum Hand-Werkzeug, damit Sie beim Malen schwenken können.

Werkzeuge

  • V — Verschieben
  • M — Auswahlrechteck
  • L — Lasso
  • W — Zauberstab / Schnellauswahl / Objektauswahl
  • C — Freistellen
  • B — Pinsel
  • E — Radiergummi
  • T — Text
  • J — Korrekturgruppe
  • S — Kopierstempel
  • G — Verlauf / Füllwerkzeug
  • I — Pipette
  • P — Zeichenstift
  • U — Formen
  • O — Abwedeln / Nachbelichten / Schwamm
  • H — Hand
  • Z — Zoom
  • R — Ansicht drehen

Datei, Bearbeiten und Korrekturen

  • ⌘O / Ctrl+O — Öffnen
  • ⌘S / Ctrl+S — Speichern
  • ⇧⌘S / Ctrl+Shift+S — Speichern unter
  • ⌘⌥⇧W / Ctrl+Alt+Shift+W — Exportieren als
  • ⌘T / Ctrl+T — Frei transformieren
  • ⌘⌥I / Ctrl+Alt+I — Bildgröße
  • ⌘⌥C / Ctrl+Alt+C — Arbeitsfläche
  • ⌘L / Ctrl+L — Tonwertkorrektur
  • ⌘M / Ctrl+M — Gradationskurven
  • ⇧⌘N / Ctrl+Shift+N — Neue Ebene (Dialog)
  • F7 — Ebenenbedienfeld
  • F5 — Pinseleinstellungen

Sitzt das im Muskelgedächtnis, lassen sich seltenere Befehle leichter ergänzen. Versuchen Sie beim nächsten Bild, die Werkzeugleiste seltener anzufahren.
