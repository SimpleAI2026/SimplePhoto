打开、保存与导出

修图之前先弄清文件从哪里来、改完后要存成什么。保存通常保留可再编辑的结构（例如 PSD 里的图层）；导出则是给网页、打印或发给别人看的成品（JPEG、PNG、WebP 等）。

打开与新建

  • 文件 → 打开（⌘O / Ctrl+O）：从本机选择已有图片。
  • 文件 → 新建：指定宽度、高度、背景，从空白画布开始。
  • 也可以从主页上的「打开」或「新建」进入。

在 SimplePhoto 中

作为 Chrome 扩展，打开文件会使用浏览器的文件选择框，图片在本地处理，不会上传到 SimplePhoto 服务器。文件 → 保存（⌘S / Ctrl+S）和 保存为（加上 Shift）用于写回可编辑文件。文件 → 导出 → 导出为（⌘⌥⇧W / Ctrl+Alt+Shift+W）打开导出对话框，可选格式与尺寸；快速导出为 PNG 适合马上要一张透明背景图。在浏览器里，保存/导出通常表现为一次下载。

怎么选格式

  • PSD / 类似分层格式：还要继续改图层、蒙版和文字时优先保存。
  • PNG：需要透明，或希望较少有损压缩。
  • JPEG：照片分享、体积小，但是有损，也不支持透明。
  • WebP 等：在导出对话框里按目标选择，先看预览再定质量。

仅 Photoshop 的概念

云文档、从 Lightroom 同步、Creative Cloud 文件版本历史，以及「存储到 Adobe 云」都不属于 SimplePhoto。本扩展也不申请下载管理权限，因此不会出现系统「另存到指定文件夹并覆盖原文件」的桌面级行为，而是按网页下载处理。
