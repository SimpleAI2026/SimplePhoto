Chapitre 15 · Référence

Raccourcis clavier

Les raccourcis réduisent les allers-retours du pointeur, mais inutile de tous les mémoriser d’un coup. Apprenez les touches d’outils et les commandes Fichier ou Réglages que vous utilisez chaque jour. Le tableau suit les valeurs par défaut de SimplePhoto (PhotoCraft), proches de Photoshop. Utilisez ⌘ sous macOS et Ctrl sous Windows / ChromeOS ; ⌥ est Alt, ⇧ est Maj. Si vous avez réattribué les raccourcis dans les Préférences, c’est la carte actuelle de l’application qui l’emporte.

Dans SimplePhoto

Consultez ou changez les liaisons dans la section clavier de Réglages / Préférences (proche de la boîte Raccourcis clavier de Photoshop). Quand plusieurs outils partagent une touche, appuyez à nouveau pour parcourir le groupe. La barre d’espace bascule temporairement vers l’outil Main pour vous déplacer tout en peignant.

Outils

  • V — Déplacement
  • M — Sélection
  • L — Lasso
  • W — Baguette magique / Sélection rapide / Sélection d’objet
  • C — Recadrage
  • B — Pinceau
  • E — Gomme
  • T — Texte
  • J — Groupe de correction
  • S — Tampon de clonage
  • G — Dégradé / Pot de peinture
  • I — Pipette
  • P — Plume
  • U — Formes
  • O — Densité − / Densité + / Éponge
  • H — Main
  • Z — Zoom
  • R — Rotation de l’affichage

Fichier, édition et réglages

  • ⌘O / Ctrl+O — Ouvrir
  • ⌘S / Ctrl+S — Enregistrer
  • ⇧⌘S / Ctrl+Shift+S — Enregistrer sous
  • ⌘⌥⇧W / Ctrl+Alt+Shift+W — Exporter sous
  • ⌘T / Ctrl+T — Transformation libre
  • ⌘⌥I / Ctrl+Alt+I — Taille de l’image
  • ⌘⌥C / Ctrl+Alt+C — Taille du canevas
  • ⌘L / Ctrl+L — Niveaux
  • ⌘M / Ctrl+M — Courbes
  • ⇧⌘N / Ctrl+Shift+N — Nouveau calque (boîte de dialogue)
  • F7 — Panneau Calques
  • F5 — Paramètres du pinceau

Une fois ces raccourcis dans la mémoire musculaire, les commandes plus rares s’ajoutent plus facilement. Sur votre prochaine image, essayez de visiter moins souvent la barre d’outils.
