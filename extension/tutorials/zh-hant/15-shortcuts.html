快速鍵

快捷鍵能減少鼠標往返，但不必一次背完。先記住工具鍵和最常用的檔案 / 調整命令。下表按 SimplePhoto（PhotoCraft）預設習慣列出，與 Photoshop 大多相近。macOS 用 ⌘，Windows / ChromeOS 用 Ctrl；⌥ 對應 Alt，⇧ 爲 Shift。若你在偏好設定裡改過快捷鍵，以軟體當前設定為準。

在 SimplePhoto 中

查看或修改快捷鍵請到設定 / 偏好設定中的鍵盤相關頁面（與 Photoshop 的「鍵盤快捷鍵」類似）。同一組工具共用一個鍵時，反覆按該鍵可循環。空格暫時切換抓手，便於一邊繪製一邊平移。

工具

  • V — 移動
  • M — 選框
  • L — 套索
  • W — 魔術棒 / 快速選取 / 物件選取
  • C — 裁剪
  • B — 筆刷
  • E — 橡皮擦
  • T — 文字
  • J — 修復類工具
  • S — 仿製印章
  • G — 漸變 / 油漆桶
  • I — 吸管
  • P — 鋼筆
  • U — 形狀
  • O — 減淡 / 加深 / 海綿
  • H — 抓手
  • Z — 縮放
  • R — 旋轉檢視

檔案、編輯與調整

  • ⌘O / Ctrl+O — 開啟
  • ⌘S / Ctrl+S — 儲存
  • ⇧⌘S / Ctrl+Shift+S — 儲存爲
  • ⌘⌥⇧W / Ctrl+Alt+Shift+W — 匯出為
  • ⌘T / Ctrl+T — 任意變形
  • ⌘⌥I / Ctrl+Alt+I — 影像尺寸
  • ⌘⌥C / Ctrl+Alt+C — 畫布大小
  • ⌘L / Ctrl+L — 色階
  • ⌘M / Ctrl+M — 曲線
  • ⇧⌘N / Ctrl+Shift+N — 新增圖層（對話框）
  • F7 — 圖層面板
  • F5 — 筆刷設定

把這些鍵練成肌肉記憶之後，再去學更冷門的命令會輕鬆得多。下一張圖練習時，試着儘量少把指針送回工具欄。
