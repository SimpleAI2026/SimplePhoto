第 02 章 · 基礎

開啟、儲存與匯出

修圖之前先弄清檔案從哪裡來、改完後要存成什麼。儲存通常保留可再編輯的結構（例如 PSD 裡的圖層）；匯出則是給網頁、列印或發給別人看的成品（JPEG、PNG、WebP 等）。

開啟與新增

  • 檔案 → 開啟（⌘O / Ctrl+O）：從本機選取已有圖片。
  • 檔案 → 新增：指定寬度、高度、背景，從空白畫布開始。
  • 也可以從首頁上的「開啟」或「新增」進入。

在 SimplePhoto 中

作為 Chrome 擴充功能，開啟檔案會使用瀏覽器的檔案選取框，圖片在本地處理，不會上傳到 SimplePhoto 服務器。檔案 → 儲存（⌘S / Ctrl+S）和 儲存爲（加上 Shift）用於寫回可編輯檔案。檔案 → 匯出 → 匯出為（⌘⌥⇧W / Ctrl+Alt+Shift+W）開啟匯出對話框，可選格式與尺寸；快速匯出爲 PNG 適合馬上要一張透明背景圖。在瀏覽器裡，儲存/匯出通常表現爲一次下載。

怎麼選格式

  • PSD / 類似分層格式：還要繼續改圖層、遮色片和文字時優先儲存。
  • PNG：需要透明，或希望較少有損壓縮。
  • JPEG：照片分享、體積小，但是有損，也不支援透明。
  • WebP 等：在匯出對話框裡按目標選取，先看預覽再定品質。

僅限 Photoshop 的概念

雲檔案、從 Lightroom 同步、Creative Cloud 檔案版本歷史，以及「存儲到 Adobe 雲」都不屬於 SimplePhoto。本擴充功能也不申請下載管理權限，因此不會出現系統「另存到指定資料夾並覆蓋原檔案」的桌面級行爲，而是按網頁下載處理。
