Chapter 09 · Type

文字

Type and text

文字图层让标题、说明和标注保持可编辑：只要尚未栅格化，你就可以改字句、字体和大小，而不必重画。海报、缩略图和水印都会用到它。

Type layers keep titles, captions, and labels editable: until you rasterize them, you can change wording, font, and size without redrawing. Posters, thumbnails, and watermarks all use this.

在 SimplePhoto 中

In SimplePhoto

使用 横排文字工具（T）在画布上点击或拖出文本框并输入。同组还有直排文字，以及横排/直排文字蒙版（用文字形状创建选区）。双击文字图层或使用「编辑文字」可回到输入状态。字体、字号、对齐等在选项栏或属性相关面板中调整。需要把字变成普通像素以便用画笔破坏性地涂改时，再栅格化文字图层。

Choose the Horizontal Type Tool (T), click or drag a box on the canvas, and type. The same group has Vertical Type and Horizontal/Vertical Type Mask tools (type as a selection). Double-click the type layer or use Edit Type to return to editing. Font, size, and alignment live in the options bar or related property controls. Rasterize a type layer only when you need ordinary pixels, for example to paint over the letters destructively.

排版提示

Typesetting tips

标题与正文使用不同的字号和字重，不要把所有字都做成特大又特粗。注意行长：一行过长会很难读。文字与照片对比要足够，必要时在文字下层加半透明色块或阴影（图层样式，如果菜单中提供投影）。避免在低分辨率画布上放细线字体，导出后会发虚。

Give the title and the body different sizes and weights; not every line needs to be huge and heavy. Watch line length — very long lines are hard to read. Keep enough contrast against the photo; add a translucent panel or a drop shadow (Layer Style, when offered) if needed. Avoid hairline fonts on a low-resolution canvas; they will look soft after export.

仅 Photoshop 的概念

Photoshop-only notes

Adobe Fonts 云端激活、部分高级 OpenType 排版面板，以及和 Illustrator 之间的实时文字链接，不是本扩展的功能范围。SimplePhoto 使用本机可用字体。

Adobe Fonts activation, some advanced OpenType panels, and live type links from Illustrator are outside this extension. SimplePhoto uses fonts available on the machine / in the app.
