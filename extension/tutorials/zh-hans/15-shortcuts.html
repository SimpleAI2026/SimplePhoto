快捷键

快捷键能减少鼠标往返，但不必一次背完。先记住工具键和最常用的文件 / 调整命令。下表按 SimplePhoto（PhotoCraft）默认习惯列出，与 Photoshop 大多相近。macOS 用 ⌘，Windows / ChromeOS 用 Ctrl；⌥ 对应 Alt，⇧ 为 Shift。若你在偏好设置里改过快捷键，以软件当前设置为准。

在 SimplePhoto 中

查看或修改快捷键请到设置 / 偏好设置中的键盘相关页面（与 Photoshop 的「键盘快捷键」类似）。同一组工具共用一个键时，反复按该键可循环。空格暂时切换抓手，便于一边绘制一边平移。

工具

  • V — 移动
  • M — 选框
  • L — 套索
  • W — 魔棒 / 快速选择 / 对象选择
  • C — 裁剪
  • B — 画笔
  • E — 橡皮擦
  • T — 文字
  • J — 修复类工具
  • S — 仿制图章
  • G — 渐变 / 油漆桶
  • I — 吸管
  • P — 钢笔
  • U — 形状
  • O — 减淡 / 加深 / 海绵
  • H — 抓手
  • Z — 缩放
  • R — 旋转视图

文件、编辑与调整

  • ⌘O / Ctrl+O — 打开
  • ⌘S / Ctrl+S — 保存
  • ⇧⌘S / Ctrl+Shift+S — 保存为
  • ⌘⌥⇧W / Ctrl+Alt+Shift+W — 导出为
  • ⌘T / Ctrl+T — 自由变换
  • ⌘⌥I / Ctrl+Alt+I — 图像大小
  • ⌘⌥C / Ctrl+Alt+C — 画布大小
  • ⌘L / Ctrl+L — 色阶
  • ⌘M / Ctrl+M — 曲线
  • ⇧⌘N / Ctrl+Shift+N — 新建图层（对话框）
  • F7 — 图层面板
  • F5 — 画笔设置

把这些键练成肌肉记忆之后，再去学更冷门的命令会轻松得多。下一张图练习时，试着尽量少把指针送回工具栏。
