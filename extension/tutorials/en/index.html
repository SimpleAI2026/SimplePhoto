SimplePhoto tutorials

Learning path

This curriculum follows a familiar Photoshop-style path, but every in-app step is written for SimplePhoto. SimplePhoto is a local editor that runs in Chrome; its engine is the open-source PhotoCraft project, with menus and tools named close to Photoshop so the two are easier to compare.

On the editor Home screen, Learn opens this index in a new tab. The pages ship inside the extension and no longer leave the app for an external tutorial site. Use the language control at the top to switch among English, Simplified Chinese, Traditional Chinese, Japanese, Korean, German, and French. If the editor is set to another language, these tutorials open in English.

Starting in SimplePhoto

The extension opens on a Home screen for new or existing images, with recent files on the right. The left rail has Home and Learn. The title bar can switch workspace, appearance, and UI language. Toggle the Layers panel with F7.

Where this is not Photoshop

SimplePhoto does not sign into an Adobe account and has no Firefly / Generative Fill, cloud documents, or Creative Cloud Libraries. Treat Neural Filters and other Adobe-cloud features as Photoshop-only. This guide marks those ideas instead of inventing buttons that are not in the app.

Suggested path

Get comfortable with the workspace, file I/O, and layers first; then selections and adjustments; compositing and non-destructive habits come last. You do not need to finish in one sitting — practice each chapter on a photo of your own.
