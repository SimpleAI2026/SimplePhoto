Keyboard shortcuts

Shortcuts cut down on pointer travel, but you do not need to memorize them all at once. Learn the tool keys and the file or adjustment commands you use daily. The table follows SimplePhoto (PhotoCraft) defaults, which are close to Photoshop. Use ⌘ on macOS and Ctrl on Windows / ChromeOS; ⌥ is Alt, ⇧ is Shift. If you remapped shortcuts in Preferences, the app’s current map wins.

In SimplePhoto

Review or change bindings in the keyboard section of Settings / Preferences (similar to Photoshop’s Keyboard Shortcuts dialog). When several tools share a key, press it again to cycle the group. Space temporarily switches to the Hand tool so you can pan while painting.

Tools

  • V — Move
  • M — Marquee
  • L — Lasso
  • W — Magic Wand / Quick Selection / Object Selection
  • C — Crop
  • B — Brush
  • E — Eraser
  • T — Type
  • J — Healing group
  • S — Clone Stamp
  • G — Gradient / Paint Bucket
  • I — Eyedropper
  • P — Pen
  • U — Shapes
  • O — Dodge / Burn / Sponge
  • H — Hand
  • Z — Zoom
  • R — Rotate View

File, edit, and adjustments

  • ⌘O / Ctrl+O — Open
  • ⌘S / Ctrl+S — Save
  • ⇧⌘S / Ctrl+Shift+S — Save As
  • ⌘⌥⇧W / Ctrl+Alt+Shift+W — Export As
  • ⌘T / Ctrl+T — Free Transform
  • ⌘⌥I / Ctrl+Alt+I — Image Size
  • ⌘⌥C / Ctrl+Alt+C — Canvas Size
  • ⌘L / Ctrl+L — Levels
  • ⌘M / Ctrl+M — Curves
  • ⇧⌘N / Ctrl+Shift+N — New Layer (dialog)
  • F7 — Layers panel
  • F5 — Brush Settings

Once these are in muscle memory, less common commands are easier to add. On your next image, try to visit the toolbar less often.
