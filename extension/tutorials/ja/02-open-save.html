第 02 章 · 基礎

開く、保存、書き出し

編集の前に、ファイルの入り方と、最終的に何にしたいかを決めます。保存は、たいてい再編集できる構造を残します（たとえば PSD のレイヤー）。書き出しは、ウェブ、印刷、ほかの人に渡すための完成ファイル（JPEG、PNG、WebP など）を作ります。

開くと新規

  • ファイル → 開く（⌘O / Ctrl+O）は、ディスク上の既存画像を選びます。
  • ファイル → 新規 は、幅・高さ・背景を指定した空白のカンバスを作ります。
  • ホーム画面にも、同じ「開く」と「新規」があります。

SimplePhoto では

Chrome 拡張機能なので、「開く」はブラウザのファイル選択になります。編集は自分のマシン上で行われ、SimplePhoto が写真を SimplePhoto のサーバーへアップロードすることはありません。ファイル → 保存（⌘S / Ctrl+S）と 名前を付けて保存（Shift を追加）は、再編集できるファイルを書き出します。ファイル → 書き出し → 書き出し形式を指定（⌘⌥⇧W / Ctrl+Alt+Shift+W）は形式とサイズのオプションを開き、PNG としてクイック書き出し は透明なビットマップをすぐ得るのに便利です。ブラウザでは、保存／書き出しは通常ダウンロードとして現れます。

形式の選び方

  • PSD などのレイヤー付き形式：レイヤー、マスク、文字がまだ必要なあいだはこちらを優先します。
  • PNG：透明度が要るとき、または非可逆圧縮を避けたいとき。
  • JPEG：共有向けのコンパクトな写真。非可逆で、透明度はありません。
  • WebP など：書き出し形式を指定で目的に合わせて選び、品質を決める前にプレビューを確認します。

Photoshop のみのメモ

クラウドドキュメント、Lightroom 同期、Creative Cloud のバージョン履歴、「Adobe クラウドに保存」は SimplePhoto にはありません。この拡張機能は downloads 権限も要求しないため、選んだフォルダへデスクトップアプリのように上書き保存はできず、ブラウザのダウンロードの流れを使います。
