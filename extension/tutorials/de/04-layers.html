Ebenen

Ebenen verhalten sich wie gestapelte Folien: die obere kann die untere verdecken, Sie können sie aber verschieben, ausblenden oder abblenden, ohne die Pixel darunter zu zerstören. Ernsthafte Bearbeitung beginnt fast immer damit, nicht alles in eine einzige Hintergrundebene zu malen.

Wozu das Ebenenbedienfeld da ist

  • Die Stapelreihenfolge sehen und per Ziehen umordnen.
  • Mit dem Auge eine Ebene ein- oder ausblenden.
  • Deckkraft und den Füllmodus ändern (den brauchen Sie später ständig).
  • Zusammengehörige Ebenen gruppieren, damit die Liste lesbar bleibt.

In SimplePhoto

Öffnen Sie Fenster → Ebenen (F7). Eine Ebene legen Sie über das Menü Ebene oder die Schaltfläche im Bedienfeld an. ⇧⌘N / Ctrl+Shift+N öffnet den Dialog Neue Ebene; ⌥⇧⌘N / Ctrl+Alt+Shift+N legt sofort eine an. Sie können auch duplizieren, nach unten reduzieren oder auf eine Ebene reduzieren. Rasterisieren Sie, wenn Text, Formen oder ein Smart-Objekt normale Pixel werden sollen. Das Konvertieren in ein Smart-Objekt unterstützt nicht-destruktive Transformationen (siehe Kapitel 14).

Praktische Gewohnheiten

Benennen Sie Ebenen so, dass Sie den Stapel nächste Woche noch lesen. Haut, Himmel und Text gehören auf getrennte Ebenen. Läuft ein Schritt schief, blenden Sie diese Ebene aus oder löschen sie; der Hintergrund bleibt. Bewegt sich die Hintergrundebene nicht, wandeln Sie sie zuerst in eine normale Ebene um.

Nur in Photoshop

Videoebenen, einige 3-D-Ebenentypen und mit Adobe Stock oder Cloud-Bibliotheken verknüpfte Ebenen liegen außerhalb dieser Erweiterung. Das Ebenenmodell von SimplePhoto zielt auf Standbildbearbeitung und Compositing.
